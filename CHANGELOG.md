# Changelog

## 1.3.0 - 2026-11-25

### Added

- Per-plugin enable, disable, and uninstall controls alongside batch actions.
- Removable custom search chips inside the search box, matching any entered
  term, with combinable disabled and user-installed filters.
- Hidden-selection counts and review, explicit selection controls, and
  uninstall confirmation showing eligible and skipped plugins.
- Searchable uninstall history with backup size, clearer restore conflicts,
  specific-backup deletion confirmation, and a way to find restored plugins.
- Confirmation before enabling automatic backup expiry, including a warning
  about existing expired backups.
- Settings section navigation and controls for all supported bar placements.

### Changed

- Redesigned plugin rows, filter controls, settings, and preview images.
- Improved keyboard navigation, focus visibility, and accessible control names.
- Show progress and detailed partial-failure summaries for batch actions and
  backup cleanup, including results inside settings.
- Clarified restore, linked-backup, and retention behavior in the interface and
  documentation.

## 1.2.1 - 2026-11-17

- Fixed bar placement detection for string and object entries, including
  center-begin, center-end, and tray placements.
- Documented MIT licensing and runtime dependencies for marketplace submission.

## 1.2.0 - 2026-11-17

- Added persistent default filters, native-plugin visibility, bar icon options,
  backup retention, and optional uninstall-confirmation skipping.
- Added backup disk usage and confirmed bulk cleanup.
- Updated settings documentation and previews.

## 1.1.0 - 2026-11-17

- Added local uninstall backups, disabled restore, and permanent backup deletion
  with protections for installed and linked plugins.
- Added feedback links and version-aware bug-report and feature-request forms.

## 1.0.0 - 2026-11-17

- Initial release with a searchable plugin list, filters, batch management,
  protected plugins, and scrollable native Omarchy shell UI.
